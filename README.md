# Trabajo_Poo_Aplicacion_Escritorio

Proyecto numero 3 de ingeniería en Software y datos (IU Digital de Antioquia)

Esta es mi aplicación de escritorio hecha en Java con Swing y JDBC para conectarse a una base de datos SQLite (estudiantes.db).

esta permite validar la conexión, consultar e insertar registros y exportar los datos en formato CSV.
